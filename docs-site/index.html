PSO Web — Cloud Ecosystem Framework

PSO Web Framework

One ecosystem. Independent teams. Unified architecture.

Build independently. Integrate seamlessly. Operate securely.

A declarative, cloud-oriented ecosystem framework for the entire lifecycle of distributed web applications: development, integration, security, infrastructure, deployment and operations. Create Node.js orchestrators and Spring Boot microservices through structure, conventions and declarative contracts, then deploy and operate them with plans, pipelines, blue-green releases and rollback, so independent teams keep one consistent architecture.

What PSO gives you

Every card links to the page that explains it, including what is not finished.

CLI-driven development Create workspaces, orchestrators, services, modules and routes with generators that edit your code through the TypeScript AST and re-validate it.Structural discovery The tree is parsed, never executed: files are classified by name and place, validated and turned into a deterministic manifest.Module composition MODULE.pso.ts composes controllers and providers. ROUTES.pso.ts declares what is exposed. Decorators alone expose nothing.Secure routing Deny by default. JWT/JWKS guards fail closed, scopes are enforced twice, and an inconsistent registry stops start-up.Microservice communication One public orchestrator forwards to declared Spring Boot services with hygienic headers. Services validate tokens themselves.Optional event dispatch One event contract for TypeScript and Java with independent Redis Streams, RabbitMQ and Kafka adapters. At-least-once, disabled by default.Integrated DevOps Partialpso dev, build, Docker/Compose/CI generation and release-based deployment with rollback. Running containers is not yet verified here.

Three files, one invariant

An endpoint exists if and only if it is declared in the route registry, belongs to a valid module, references a compatible decorated action and passes validation.
