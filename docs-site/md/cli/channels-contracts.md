# pso channels:contracts

> Generate the client-safe TypeScript contracts of the registered channels (names, parameters, event and command payloads) for a front end; internal channels, publishers, scopes and policies are never included

Generate the client-safe TypeScript contracts of the registered channels (names, parameters, event and command payloads) for a front end; internal channels, publishers, scopes and policies are never included.

## Usage

```text
pso channels:contracts [--from <orchestrator folder> | --service <orchestrator>] [--out src/integrations/pso/types.ts] [--json]
```

## Flags

`--from`, `--service`, `--out`, `--json`.

## Examples

```bash
pso channels:contracts --from ../gw
pso channels:contracts --service gw --out web/src/integrations/pso/types.ts
```

## What it changes

- Writes the client-safe TypeScript contracts of the registered, non-internal channels. It never includes publishers, scopes, authorization methods, unregistered channels or addresses.

## Failure cases

- The folder must be a PSO orchestrator (official `src/.app/` and `src/modules/`, or a 0.1 `src/routes/`). An existing file that was not generated by PSO is left untouched.

## Exit codes

`0` on success, `1` when the command ran and failed. See the [exit code table](cli/index.md#exit-codes).
